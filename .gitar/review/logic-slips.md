# Logic slips: the five bug classes Gitar finds most on agent PRs
Why (owner, 13 Nov 2026, chose "A+B+D"): Gitar flagged a finding on 66 of 93 PRs (#3960-#4059, 168 findings); about 100 were logic slips in these five classes. Agents check their diff against this file, and the rest of `.gitar/review/`, before the first push (AGENTS.md "Shipping"); Gitar raises them as it does today, naming the class.

1. **A failure that reads as success:** for every read, call or parse the diff adds, what does the person see when it fails (exception, empty reply, 4xx/5xx, timeout)? A failed read must not show as "nothing found", "done" or "sent", and an unreadable answer must not count as "no problem". A test plays the failure. (#4018 checkJob silently did nothing while a check ran; #4058 an unreadable refusal read let a post through.)
2. **State and timing:** a value read once and written back later (stale), two writers of one state, a later step that undoes an earlier one, "running" vs "done" read from two places. (#3967 the pair PATCH overwrote a body edited after it was read; a second stop wiped the kept count.)
3. **Counts, caps and boundaries:** a budget spent before the request or refunded for one that was sent, a cap with no day boundary, time zone or restart rule, a `first: N` page that hides the row you need, 0, 1 and fractional values. (Job-page budget burned by cut requests; `checkRuns(first: 20)` hid Gitar's run.)
4. **The change reaches other code:** grep every caller, test, label reader, glob, log-line parser and doc of what you changed (a function, a label's words, a log line, a file name) and run the ones it reaches. (ship-watch's glob matched the new label; an existing test asserted the old `init()` text and went red.)
5. **Parsing outside input:** unclosed or self-closing tags, an element still open at the end of input, a charset or encoding declaration, a structured value (JSON-LD) against a page heading. (An unclosed `<a>` hid every later link.)
