# Final desktop wizard, Settings, native and update coverage audit

**Verdict: this bounded desktop scope is not fully translated.** Existing static/catalog coverage is substantial, but the normal paths below still emit authored English under de/fr/it/es/ro/ru. English itself is the intended source language. This report makes no claim about extension or other renderer pages, which other panes audit; Focus/Jobs belongs to root's #3526 work.

## Snapshot and method

- Pinned final snapshot: `e3fbc289ea20e3655f4e98c4bbf00f9c9df4820a` (origin/main observed 7 Nov 2026). Initial inspection used `63ac25faa78d7038fbb5bf1e63221458b0ef1265`; the audited gap files have no diff between those snapshots. Final line evidence below is from e3fbc289.
- Read prior `docs/superpowers/specs/2026-11-07-desktop-multilanguage-design.md`, its implementation plan, and the prior final-copy-audit brief/audience audit. The spec explicitly requires ordinary errors, native copy, onboarding, accessibility and dynamic branches; it excludes user/employer/provider/model prose, diagnostics and stored content. Old unchecked plan boxes are historical, not proof that a current surface is missing.
- Read source directly through `git show <snapshot>:<path>`; no checkout or product edits. Traced producers through actual IPC/render consumers. Inspected wizard and Settings HTML text/attributes; unbound candidates there were proper names, URLs, credential examples and the deliberate RESET token, not missing prose.
- Catalog-only execution in an isolated in-memory Node VM loaded the snapshot's bundled registrars. **1,322 unique literal catalog references** from **45 selected modules plus index.html wizard/Settings ranges** were present in all seven locale maps: **9,254/9,254 locale/key pairs**, zero missing entries. Plain-string interpolation parameter sets matched English in all checked locales. The only unchanged English phrase longer than 18 characters found by that narrow heuristic was the intentional product name `Google Jobs (SerpApi)` (six non-English catalogs).
- This denominator is referenced keys, not all UI strings. Dynamic/computed key references, all plural-form linguistic quality, every branch and screen layout are not certified by that measurement. Escaping strings below have no catalog lookup, so key parity cannot catch them.
- No live app, account, updater, installer, CV, store, owner data, request or AI invocation was used. No unit suites were run against a mismatched checkout. Only source/catalog inspection and pure catalog formatting ran.

## Exclusions and repair boundaries

- Keep raw user/CV/job/company/AI headings, summaries, notes, provider response/error details, paths, URLs, filenames, accounts, keys and actual log lines unchanged. Their authored surrounding labels are not excluded.
- Preserve canonical task kinds, pipeline TASKS/result regexes, stored event/status fields, JSON keys, session/queue IDs, source markers, day='today', channel IDs, reset word RESET and button/action identities. Existing `quit-labels.taskLabel` is an appropriate native display seam.
- Product/provider names (Jobadabra, Claude, Claude Sonnet, Codex, Notion, Telegram, LinkedIn, GitHub, Cloudflare, Indeed, Adzuna, Jooble, Google Jobs/SerpApi, Pro), technical examples (`sk-…`, `ntn_…`, chrome://extensions), paths such as Jobadabra Backups and terminal commands are not counted as missing English prose.
- `main.js:393` build/development strings and core's DEV tag are build diagnostics. Snapshot date at strategy-draft-handlers.js:112 is persisted Notion snapshot naming, not evidence to relocalize stored content. Demo-only authored strings at draft-handlers:29 are separately identifiable and are not the basis of gap #10.
- No edits, new PR, tests, harness or owner-state mutation were performed. Keep the existing implementation worktree intact. Prior PR watches are terminal MERGED; root owns the current Focus/Jobs PR.
