Technical reports

Anonymous errors and counts, never your answers, CV, emails or names. Turn off any time in Settings → Advanced.

What is sent

Jobadabra sends technical reports (errors, forms it couldn't fill, anonymous counts like forms filled and interviews) to improve it for everyone, asks our service for shared fixes to forms that trip it up (by the control's anonymous shape, never its text), and shares which employer career pages you use, with two labels (your kind of role and your region), to grow the shared pool of employers. Never your answers, CV, emails or names. Turn either off any time in Settings → Advanced.

How each option works

Start with Free (nothing to set up), or bring your own Claude or OpenAI: an API key (you pay per use, usually a few dollars a month) or your own Claude Code / Codex (your Claude or ChatGPT plan).

  1. Open console.anthropic.com → API keys and sign up or sign in (a separate account from a Claude.ai subscription).
  2. New account? Go to Billing and add a small amount of credit, e.g. $5: it lasts weeks. Keys don't work without credit.
  3. Back in API keys: click Create Key, name it "Jobadabra", copy it, and paste it here.

  1. Open platform.openai.com → API keys and sign up or sign in (a separate account from a ChatGPT subscription).
  2. New account? Go to Billing and add a small amount of credit, e.g. $5: it lasts weeks. Keys don't work without credit.
  3. Back in API keys: click Create new secret key, name it "Jobadabra", copy it, and paste it here.

With Free, AI requests go through the Jobadabra website to an open AI model (nothing is stored). With your own key they go straight from this Mac to Claude or OpenAI.
